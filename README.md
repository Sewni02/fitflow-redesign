# FitFlow Redesign

Redesign of the FitFlow fitness tracking app - AI-powered personalized
workout plans, social community features, and improved nutrition tracking.

## Tech Stack
- Frontend: Flutter (iOS / Android / Web)
- Backend API: Next.js / NestJS
- AI Service: FastAPI (Python) + TensorFlow/PyTorch
- Database: PostgreSQL (Supabase)
- Auth: Supabase Auth
- Real-time: Supabase Realtime / WebSockets
- Cache: Redis

## Project Structure
See /frontend, /backend, /ai-service, and /docs.

## Getting Started
1. Clone the repo
2. Set up .env files in backend/ and ai-service/ (see .env.example)
3. Run each service - see individual READMEs in each folder
